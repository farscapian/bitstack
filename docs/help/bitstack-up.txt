bitstack up -- deploy the bitcoind + electrs stack

Requires ./setup.sh to have run at least once (docker installed, and this
user an active member of the docker group). Every 'bitstack' command,
including this one, initializes the single-node docker swarm itself first
if it isn't already active -- no separate step needed.

Usage:
  bitstack up

What it does:
  1. Builds the local/bitcoind, local/electrs, and local/tor images, each
     tagged by resolved version -- skips the build for any image whose tag
     is already present locally, so re-running is fast
  2. Prepares ~/.bitcoin (creates the directory, installs the default
     bitcoin.conf if one is not already there)
  3. Deploys the 'bitstack' docker stack (bitcoind + electrs + tor services)
  4. Waits (up to a minute) for the tor service to publish its hidden
     service and prints the resulting onion address -- electrs' Electrum
     RPC port (50001), reachable over Tor without opening any firewall
     ports. See: docs/help/bitstack-get-onion.txt

Safe to re-run: 'docker stack deploy' converges the stack to match
btc-stack.yml without discarding existing data (including the onion
address, which is stable across redeploys).

Help:
  bitstack up help
  bitstack help up
