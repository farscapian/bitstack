bitstack down -- stop the bitcoind + electrs stack

Usage:
  bitstack down

What it does:
  Removes the 'bitstack' docker stack (docker stack rm) and waits for its
  services to fully terminate.

Node data under ~/.bitcoin and the electrs database volume are left in
place -- 'bitstack up' picks up right where it left off. Use 'bitstack
reset' to discard data instead.

Safe to re-run: a no-op (with a message) if the stack is not running.

Help:
  bitstack down help
  bitstack help down

See also: docs/help/bitstack-up.txt, docs/help/bitstack-reset.txt,
docs/help/bitstack-bitcoin-cli.txt, docs/help/bitstack-tor.txt
