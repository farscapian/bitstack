bitstack -- control the bitcoind + electrs docker-swarm stack

Run from the bitstack repo root, as your regular login user (not root), an
active member of the docker group. Requires ./setup.sh to have installed
docker first -- every 'bitstack' command then initializes the docker swarm
itself if needed, before doing anything else. 'bitstack up' builds the
local/bitcoind, local/electrs, and local/tor images itself.

Commands:

  up                  deploy the bitcoind + electrs + tor stack
  down                stop the stack; node data is left in place
  restart             stop then redeploy the stack (down + up)
  reset               stop the stack and DELETE all node data (~/.bitcoin/*)
  bitcoin-cli         run bitcoin-cli against the running bitcoind container
  bitcoind            tail bitcoind's logs, or print its bitcoin.conf
  electrs             tail electrs' logs, rotate the onion address, or set a specific private key
  get-onion           print the onion address publishing electrs' Electrum RPC
  sparrow             install (first run) and launch Sparrow (local if co-resident, else onion)

Use 'bitstack <command> help' for detailed help on any command.
Use 'bitstack help <command>' as an equivalent form.

Global Options (valid anywhere on the command line):
  -v, --verbose       Show diagnostics (--verbose is a full alias for -v)
  -q, --quiet         Suppress status messages (errors still shown)
  --timestamp         Prefix each line with ISO datetime
  --log-id=ID         Mirror output to ~/.agentstack/logs/bitstack-<ID>.log

First-time setup (docker, docker group membership): ./setup.sh --
'bitstack sparrow' installs the Sparrow wallet itself, on its own first run.
